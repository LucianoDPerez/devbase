# OWASP Top 10 (essentials)

Broken access control, cryptographic failures, injection, insecure design,
security misconfiguration, vulnerable components, auth failures, data/software
integrity failures, logging failures, SSRF.

Level: deterministic where Semgrep/CodeQL rules exist, contextual otherwise.
AI-generated code gets the aggressive ruleset; Veracode 2025-2026: ~45% of AI
samples fail standard security tests.
